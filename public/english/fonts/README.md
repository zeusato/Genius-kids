# English Garden typography

Noto Serif variable WOFF2, weights 400–600, normal and italic. Latin and Vietnamese subsets are bundled so accented headings use the same family and metrics as the surrounding letters, including offline.

- Source: Google Fonts, https://fonts.google.com/noto/specimen/Noto+Serif
- Retrieved 2026-09-23 from the Google Fonts CSS API (version 33).
- License: SIL Open Font License 1.1; see `OFL.txt`.
- UI/body text reuses the locally bundled Nunito fonts under `public/hub/fonts` and their license.
- Font styles are scoped to the English module in `src/english/book.css`.

All WOFF2 assets are part of the existing PWA core-asset policy.
