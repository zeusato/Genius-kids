# Google sign-in assets

- Logo: https://developers.google.com/static/identity/images/g-logo.png (official gradient G, unmodified).
- Button guidance: https://developers.google.com/identity/branding-guidelines (retrieved 2026-10-04).
- Font: Google Sans Medium (500), fetched from Google Fonts CSS API with the subset text `Đăng nhập bằng Google`. Kept locally as WOFF2 for offline use. If the label changes, regenerate the subset.
- Font source: https://github.com/google/fonts/tree/main/ofl/googlesans — license included in `GoogleSans-OFL.txt`.

Logo use follows Google's brand guidelines; the font's license does not grant rights to the Google trademark.
